# Kolibri-1 ninja game: dummy test project

**This is a demo for testing only.**

`v1/index.html` and `v2/index.html` are 2D ninja fighting games generated by Aleph Alpha's **Kolibri-1** model through the Tesseracted API on 7 Oct 2026. They are published exactly as the model wrote them, with no edits by a human.

- **Round 1 (`v1/`)**: built from one prompt.
- **Round 2 (`v2/`)**: Kolibri-1 got its round-1 code plus a list of the bugs found in testing, and was asked to fix them.

Bugs are left in on purpose. In round 1, one hit ends the fight, jump and the special move do nothing, and the CPU walks away from you. In round 2, nobody can move at all.

`play.html` and `play-v2.html` are small wrapper pages (not written by Kolibri). They show the game in a frame and send one anonymous request to a public counter (abacus.jasoncameron.dev) to count page opens. They set no cookies, use no storage, and send no personal data.
